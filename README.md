✦ Overview

RippleFiles is a customized version of "RippleFiles-FileManager" (https://github.com/GokulSB/RippleFiles-FileManager), an Android file manager built with Kotlin and Jetpack Compose.

This project builds upon the original application with a focus on a distinctive visual identity, interface refinements, and a more cohesive user experience.

«A familiar foundation, reimagined through a more personal design direction.»

✨ Project Focus

- Visual identity — a distinct brand and consistent visual language.
- UI/UX refinement — thoughtful interface adjustments and attention to detail.
- Android experience — customization built around the existing Android application.
- Continuous improvement — iterative refinements as the project evolves.

🛠️ Built With

Technology| Role
Kotlin| Primary programming language
Jetpack Compose| Declarative UI
Gradle| Build automation
Android SDK| Android application platform

🚀 Getting Started

Prerequisites

- Android Studio or a compatible Android development environment
- JDK compatible with the project's Gradle configuration
- Android SDK components required by the project

Build the application

Clone this repository:

git clone <YOUR_REPOSITORY_URL>
cd RippleFiles-FileManager/android

Build the debug APK:

./gradlew assembleDebug

The generated APK is typically located at:

app/build/outputs/apk/debug/app-debug.apk

«Build requirements may vary depending on the project's Gradle and Android SDK configuration.»
